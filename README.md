# Skim — Free Offline Installer

![Category](https://img.shields.io/badge/PDF_Reader-blue?style=flat-square)

## About

Skim is a free, open-source PDF reader and note-taker specifically designed for macOS. It provides tools for annotation, highlighting, and note-taking directly on PDF documents, making it popular among academics and researchers. Skim supports AppleScript for automation, integrates with LaTeX workflows, and offers features like a presentation mode and split view for comparing documents.

## Common Problems & Limitations

- **macOS Only** — No Windows or cross-platform support
- **Development Pace** — Updates less frequent than commercial alternatives
- **No Cloud Sync** — Manual file management required for cross-device access
- **Limited Editing** — PDF editing beyond annotation not supported
